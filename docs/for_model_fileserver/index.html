STScI CDBS Files

These files are hosted by the Space Telescope Science Institute, not by this site. Download them directly from the STScI Reference Atlases page.

SPISEA uses the STScI CDBS infrastructure for HST filter throughputs and additional atmosphere models. You need to set up a cdbs/ directory containing comp/, mtab/, and grid/ sub-directories. Download these two files from STScI and untar them; the sub-directories will appear under grp/redcat/trds/ inside the archive:

  • synphot1_throughput-master.tar — HST filter throughputs (comp/ and mtab/ directories). Use a version dated 2024-03-22 or later to enable Roman Space Telescope filters.
  • synphot5_pheonix-models.tar — Phoenix atmosphere models (grid/ directory).

After untarring, move comp/, mtab/, and grid/ directly into your top-level cdbs/ directory, then point the PYSYN_CDBS environment variable there.

Version Compatibility Notes

SPISEA Code Version Data Grid Version Notes
v3.1 (2026-11-10) grid_version 3.1 Current release. Requires updated spisea_models.tar.gz and spisea_cdbs.tar.gz (grid_version 3.1). Adds brown dwarf models with non-solar metallicities (FlameSkimmer/RedDiamondback atmospheres). Migrated from pysynphot to synphot/stsynphot.
v2.5 (2026-07-17) grid_version 3.0 Brown dwarf support (Phillips2020, Marley2021 evolution; Phillips2020, Meisner2023 atmospheres). Added COSMIC binary evolution. Data grid version 3.0 was released alongside this code version (note: the data grid was labeled 3.0 and the code version 2.5 to re-align numbering).
v2.2–v2.4 (2026-01–03) grid_version < 3.0 See release notes for data requirements. These versions added SynthPop compatibility, Roman filter support, Euclid filters, and Rubin Observatory filters.
v2.1.4–v2.1.15 (2022–2025) grid_version 1.1+ Grid version tracking introduced in v2.1.4. Expanded MISTv1 age range, added Roman/NACO filter support, various extinction law additions.
v2.0–v2.1.3 (2020–2022) Unversioned Original SPISEA release (renamed from PyPopStar in v2.0). No grid version tracking.
